# عدسة HD

تطبيق كاميرا احترافي لأندرويد (Kotlin + CameraX) — أعلى دقة وأعلى FPS يدعمها الجهاز، معالجة تلقائية للألوان والإضاءة، ومشاركة واتساب بالجودة الأصلية.

## المزايا
- صور بأعلى دقة (JPEG جودة 100) وفيديو 4K/FHD/HD بأعلى FPS مدعوم (اضغط على الشارة العلوية لتبديل الدقة/الإطارات).
- معالجة تلقائية بعد الالتقاط (ضبط مستويات + إضاءة + تباين + تشبّع) — زر العصا السحرية للتشغيل/الإيقاف (الإيقاف = ملف خام).
- زوم بالقرص، تركيز باللمس، فلاش (تلقائي/تشغيل/إيقاف)، مؤقت 3/10 ثوانٍ، شبكة + مؤشر أفق (Level)، تبديل الكاميرا، سحب يمين/يسار للتبديل بين صورة/فيديو.
- زر واتساب يرسل الملف الأصلي كمستند (بدون ضغط)، مع خيار مشاركة عبر أي تطبيق.
- الملفات تُحفظ في: Pictures/AdsaHD و Movies/AdsaHD

## البناء
ارفع المشروع إلى GitHub (فرع main) وسيعمل Workflow تلقائياً.
حمّل الملف من: Actions ← آخر عملية ← Artifacts ← AdsaHD-debug-apk
(البناء يستخدم Gradle 8.7 + JDK 17 + AGP 8.5.2 بأسلوب buildscript classpath)
